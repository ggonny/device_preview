      이 도구에서 확인되는 범위

      확인 가능 기기별 CSS 화면과 사이트 표시 영역, 물리 해상도·DPR 정보, 미디어쿼리, 줄바꿈, 레이아웃, 가로 스크롤, 브라우저 상태바·주소창·툴바·홈 인디케이터에 의해 줄어드는 영역, 가로 모드에서 safe-area 만큼 줄어드는 폭(iOS Safari·Android Chrome 기본 동작)

      브라우저 UI Safari·Chrome·Samsung Internet 의 일반적인 UI 높이를 바탕으로 한 근사치입니다. 주소창 스위치를 끄면 스크롤로 URL 바가 숨은 상태(상태바·홈 인디케이터는 유지)가 됩니다. UI 겹침을 켜면 URL 바와 툴바가 사이트 영역을 줄이지 않고 콘텐츠 위에 겹쳐지므로, 실기기에서 100vh·하단 고정 요소가 브라우저 UI에 가려지는 현상을 확인할 수 있습니다.

      다중 비교 왼쪽 상단에서 ‘다중 비교’를 선택하면 기기를 최대 4개까지 체크해 나란히 볼 수 있습니다. URL·새로고침·회전·브라우저 UI·주소창 위치·safe-area 가이드·배율은 모든 기기에 함께 적용되고, 카드마다 회전·새로고침·화면 상태·제거를 개별로 조작할 수 있습니다. 스크롤 동기화는 각 문서의 스크롤 비율(scrollTop ÷ 스크롤 가능 높이)로 맞추며, 브라우저 보안 정책상 이 도구와 같은 출처(same-origin)에서 열린 페이지에서만 동작합니다.

      safe-area 가이드 iframe 안의 페이지는 env(safe-area-inset-*) 값을 받을 수 없으므로, 노치·다이내믹 아일랜드·펀치홀·홈 인디케이터가 차지하는 영역을 빗금 가이드로 표시합니다. 가이드와 겹치는 콘텐츠는 실기기에서 가려질 수 있습니다.

      실기기 배율 공개된 화면 크기와 CSS 뷰포트를 기준으로 계산한 물리 크기 근사값입니다. 모니터 크기와 운영체제 배율에 따라 실제 크기와 차이가 날 수 있습니다.

      실행 환경 Windows 기본 스크롤바는 미리보기 화면 안의 콘텐츠 폭을 차지해 실제 휴대폰보다 좁게 배치됩니다(예: 360 기기에서 345). device_preview 폴더를 VS Code 로 열고 Go Live 로 실행하면 전용 Chrome 창이 overlay 스크롤바 모드(--enable-features=OverlayScrollbar)로 열려 실기기와 같은 폭으로 표시됩니다. 상단에 실행 환경 경고가 보이면 현재 결과의 콘텐츠 폭이 실기기와 다를 수 있습니다.

      실기기 확인 필요 iframe에서 바꿀 수 없는 UA, 실제 DPR 렌더링, 터치·hover·pointer 미디어, safe-area 환경변수, dvh/svh/lvh 단위, 대상 페이지의 <meta name="viewport"> 처리, 가상 키보드, 브라우저 자동 숨김, 실제 힌지·화면 분할 API. 스크롤바는 위 ‘실행 환경’을 참고하세요.

      브라우저 UI와 검은 노치·카메라·접힘선은 콘텐츠와 가시 영역을 확인하기 위한 시각적 근사치이므로 최종 검수는 실기기에서 진행해 주세요.

      화면이 비어 있다면 대상 사이트가 X-Frame-Options 또는 CSP frame-ancestors로 iframe 표시를 막은 경우일 수 있습니다. 이때는 오른쪽 위 새 창 버튼으로 확인해 주세요.
