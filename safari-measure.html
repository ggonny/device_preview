viewport-fit: …

모드 바꾸기: cover 로 열기 · default(auto) 로 열기 — 화면 맨 위 빨간 띠 = viewport 위 끝, 맨 아래 파란 띠 = viewport 아래 끝

Device Preview 의 Safari 브라우저 UI 높이를 실기기 값으로 확인하기 위한 독립 페이지입니다. 각 상태에서 "현재 값 기록" 을 누르고, 끝나면 "결과 복사" 로 전달해 주세요.

측정 체크리스트

각 상태에서 화면이 멈춘 뒤 "현재 값 기록"(또는 오른쪽 위 작은 패널의 "기록") 을 누르세요. 위의 "Safari 레이아웃" · "상태 메모" 를 먼저 맞춰 두면 기록에 함께 저장됩니다.

iPhone 17 Pro · Safari Compact — 각 상태에서 ① "현재 값 기록" ② 위 빨간 띠와 아래 파란 띠가 함께 보이게 스크린샷

[viewport-fit cover] (?safe=cover)

  • 세로 · 처음 진입(페이지 맨 위)
  • 세로 · 아래로 스크롤해 Safari UI 가 줄어든 상태
  • 가로 · 처음 진입(맨 위로 돌아간 뒤 회전)
  • 가로 · 스크롤 상태

[viewport-fit auto] (?safe=auto) — 위 4개를 똑같이 반복

상태 메모를 상태에 맞게 바꾼 뒤 기록하세요. 모드는 기록에 viewportFit 으로 자동 저장됩니다. 가능하면 Bottom · Top 레이아웃도 같은 순서로 반복.
